SpecDown Support

A Markdown viewer with live Mermaid diagrams for iPhone, iPad, Mac and the web.

Getting started

  • Open a file: tap Open (iPhone), Open Markdown File (iPad sidebar) or choose File → Open… (Mac) and pick any .md file, including files in iCloud Drive.
  • From other apps: use Open With… → SpecDown or the share sheet.
  • From the web: paste a web or GitHub link to a Markdown file on the start screen.
  • Try it: open the bundled Diagram Showcase to see every diagram type.

Common questions

  • A diagram shows an error. SpecDown uses Mermaid syntax; check that the diagram's code block starts with ```mermaid.
  • Images don't appear. Images linked by a full web address (https://…) need an internet connection. On iPhone and iPad, images referenced by a relative path (such as ./diagram.png) aren't shown yet; on the Mac and desktop app they load when the image is next to the file.
  • An enterprise GitHub link doesn't open. Some enterprise instances require sign-in, which SpecDown doesn't support.
