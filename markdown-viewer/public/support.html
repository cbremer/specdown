SpecDown Support

SpecDown is a reading companion for developers working with specs, design docs, READMEs and notes from their editor or AI tools. Read formatted tables, highlighted code and interactive Mermaid diagrams right in the document.

Get SpecDown

Download free for iPhone and iPad on the App Store (iOS or iPadOS 16.0 or later). You can also choose a direct desktop download for Mac, Windows or Linux.

The Mac App Store edition is coming and is currently in TestFlight, not publicly available on the Mac App Store. Windows and Linux desktop downloads have received less testing than macOS.

Getting started

  • Open a file: tap Open on iPhone, use Open Markdown File in the iPad sidebar, or choose File → Open… on Mac. Select a UTF-8 .md or .markdown file. On iPhone and iPad, Files also gives you access to iCloud Drive, OneDrive and Dropbox when those providers are installed and enabled in Files.
  • From other apps: use Open With… → SpecDown or the share sheet when the app supports it.
  • From the web: paste a public HTTPS link to a Markdown file on the start screen.
  • Try it: open the bundled Diagram Showcase to explore example Mermaid diagrams.
  • Browse a folder: on desktop or in a supported browser, choose Open Folder. In the current web app and upcoming Mac App Store edition, choose Close Folder to close the folder browser while keeping your document tabs open.

Follow saved changes on desktop

Live reload is on by default for local files opened in the desktop app. When your editor or AI agent saves changes to an open Markdown file, SpecDown refreshes the reading view while Live reload is on. Click Live beside the filename to pause, or Paused to resume. iPhone and iPad do not watch files for changes.

Install the web app

Open SpecDown in a supported browser and choose its Install app or Add to Home Screen option. Open it online first so the browser can save the app resources. Offline availability depends on what the browser has saved; online documents and remote images still need an internet connection.

Common questions

  • A diagram shows an error. SpecDown uses Mermaid syntax. Check that the diagram’s code block starts with ```mermaid.
  • A document won’t open. SpecDown supports UTF-8 Markdown files up to 8 MiB. Additional limits apply to long lines, deeply nested content and complex diagrams.
  • Images don’t appear. Images linked by a full HTTPS address need an internet connection. On iPhone and iPad, images referenced by a relative path, such as ./diagram.png, aren’t shown yet. Use a full HTTPS image address when sharing a document across platforms.
  • A link requires sign-in. SpecDown opens public links without signing in to the host. Some hosts also prevent documents from loading in other apps. Download the Markdown file, then open it in SpecDown.
  • How do I close a folder? In the current web app and upcoming Mac App Store edition, choose Close Folder in the folder browser. The upcoming Mac App Store edition also offers File → Close Folder. Your document tabs stay open. Hiding the folder browser only changes its visibility; it does not close the folder.
  • Can I use the web app offline? In a supported browser, install SpecDown as a web app or use Add to Home Screen for quick access. Open it online first; offline use depends on the app resources your browser has saved. Online documents and remote images still need an internet connection.
