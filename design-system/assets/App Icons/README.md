# App Icons

The eight interchangeable icon artworks. Desktop uses the 1024px transparent PNGs in `desktop/icons/`. iOS uses full-bleed copies in `ios/SpecDown/Assets.xcassets` (`AppIcon-<id>`). Approved masters live in `build/app-icon-sources/`.

The IDs are `original`, `flat`, `glass`, `ceramic`, `metallic`, `layered`, `minimal` and `light`, and they must match on every platform. Original is the default and the installed bundle icon. See `docs/project-app-icons/` for how they're produced.
