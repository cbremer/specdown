# ShortcutsSheet

Keyboard shortcuts sheet: a definition list of keys and actions.

**Source:** `src/features/shortcuts.js`, `.shortcuts-*`. Static rendition.

- Scrim .4, z 10002, panel min(92vw, 26rem), `radius-xl`, padding 1.25rem 1.5rem. Title is 1.1rem.
- Keys are `<kbd>` on `bg-tertiary` with a `border-color` outline and `radius-md`, at 0.85rem.
- No visible close control. Escape or a backdrop click dismisses it.
- **Target:** Modal size sm. Add the standard header close button.
