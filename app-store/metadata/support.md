# SpecDown Support (DRAFT)

SpecDown is a Markdown viewer with live Mermaid diagrams for iPhone, iPad and Mac.

## Getting started

- **Open a file:** tap **Open** (iPhone), **Open Markdown File** (iPad sidebar) or
  **File → Open…** (Mac) and choose any `.md` file, including files in iCloud Drive.
- **From other apps:** use **Open With… → SpecDown** or the share sheet.
- **From the web:** paste a web or GitHub link to a Markdown file on the start screen.
- **Try it:** open the bundled **Diagram Showcase** to see every diagram type.

## Common questions

- **A diagram shows an error.** SpecDown uses Mermaid syntax; check the diagram code
  block starts with ` ```mermaid `.
- **Images don't appear.** Web images need an internet connection; images referenced
  by a relative path must be reachable from the file's location.
- **Enterprise GitHub links don't open.** Some enterprise instances require sign-in,
  which SpecDown doesn't support.
