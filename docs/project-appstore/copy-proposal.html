Description

Read Markdown from your editor or AI assistant in a dedicated reading view.

SpecDown helps developers and people using AI tools review specs, plans, READMEs and technical notes. Open saved Markdown to read formatted tables and highlighted code, then explore Mermaid diagrams with zoom, pan and fullscreen views.

Read your documents
  • Open Markdown from Files or iCloud Drive
  • Send a Markdown document to SpecDown from a compatible app
  • Read headings, lists, tables and highlighted code
  • Jump between sections with the table of contents
  • Find text and move through matching passages
  • Switch between the rendered preview and raw Markdown
  • Compare raw Markdown and the rendered preview in split view
  • Keep several documents open in tabs
Explore Mermaid diagrams
  • View Mermaid flowcharts, sequence diagrams, state diagrams and Gantt charts
  • Expand a diagram to zoom and pan
  • Use Reset to fit the diagram to the current view
Make reading comfortable
  • Choose light, dark or system appearance
  • Use the iPad sidebar to open files and bundled examples
  • Choose from eight app icons, including a separate Light option

The bundled Diagram Showcase works offline. Local documents render on your device. Opening an online document or loading a remote image connects to its host.

No account is required. SpecDown has no ads or analytics.

What’s New

Security and reliability improvements for reading Markdown.

  • Safer handling of document content, large files and complex diagrams.
  • Web documents and remote images now require HTTPS.
  • Rejected documents leave your current document intact.
  • Improved Find behavior for documents with many matches and when the keyboard is open.
  • Diagram zoom controls center the diagram, and Reset fits the current view.
  • Better fullscreen focus and cleanup when switching documents or views.
  • Removed the diagram Link button.
  • A separate Light app icon, plus improved sizing for the existing alternate icons.

Proposed submission text

App Review notes

iPhone & iPad

SpecDown is a viewer for Markdown (.md/.markdown) documents and Mermaid diagrams. No account, sign-in or purchase is required. The viewer and bundled Sample/Diagram Showcase work offline. It reads saved documents from external editors or AI tools; it does not generate text or run an AI model.

Review on iPhone or iPad:

  1. Launch SpecDown and choose Open Diagram Showcase from the start view, or from the sidebar on iPad.
  2. Expand a diagram. Try the zoom controls, pan and Reset, then close fullscreen. The diagram toolbar has no Link action.
  3. Use Contents, Raw/Preview and Find. Try Find with the keyboard open, then dismiss it.
  4. Open Sample to inspect headings, tables, code and document comments.
  5. Use Open or Open Markdown File to choose a Markdown file from Files/iCloud Drive. Opening a document from another app is also supported.
  6. Open another document and switch tabs. Try light/dark appearance and the App Icon choices.

Remote documents and images loaded by the viewer require HTTPS. Tapped external web links open in the system browser. Documents are limited to 8 MiB, with additional rendering limits. Document-supplied active HTML, forms and styling are removed.

Annotation display, editing, import and export are disabled on native iPhone/iPad in this release. Existing stored annotation data is left untouched. HTML comments already present in a document are a separate viewing feature.

No ads, analytics or tracking SDK is included. Local documents render on the device; online documents and remote images contact their hosts. The app does not require an AI account.

Mac

SpecDown is a sandboxed Mac viewer for Markdown (.md/.markdown) documents and Mermaid diagrams. No account, sign-in or purchase is required. It reads saved documents from external editors or AI tools; it does not generate text or run an AI model.

Review on Mac:

  1. Launch SpecDown and click Try diagram showcase on the start view for an offline review.
  2. Choose File > Open... (Command-O) and select a Markdown file. The system picker grants access to the selected file.
  3. Expand a Mermaid diagram. Try zoom, drag to pan and Reset, then close fullscreen. The diagram toolbar has no Link action.
  4. Use Raw/Preview or Split to inspect the source and result. Try Contents, Command-F and more than one document tab.
  5. Choose File > Open Folder... and select a folder containing two Markdown files. Open both, then choose File > Close Folder. The folder browser closes and the document tabs stay open. Workspace files only hides or shows the browser; it does not close the folder.
  6. Quit and relaunch, then try File > Open Recent for the chosen file. If access is no longer available or the file moved, choose the file again through the system picker or the Locate access prompt. No Full Disk Access is required.

This Mac App Store build uses the App Sandbox and security-scoped bookmarks for user-selected files. It contains no self-updater or GitHub update check; updates are delivered through the App Store.

The viewer and bundled examples are local. Online documents and remote images require HTTPS and contact their hosts; external web links open in the system browser. Documents are limited to 8 MiB, with additional rendering limits. Document-supplied active HTML, forms and styling are removed.

This is a document viewer, not a Markdown editor. No ads, analytics or tracking SDK is included.

TestFlight description

SpecDown is a dedicated reader for Markdown specs, plans, READMEs and Mermaid diagrams saved from editors or AI tools. Read formatted documents, explore diagrams, compare source and preview, and move between open documents. No account is required. The bundled examples work offline.

What to Test

iPhone & iPad

  1. Open the bundled Sample and Diagram Showcase, then open your own Markdown from Files or iCloud Drive and from another app.
  2. Expand a diagram. Check centered zoom, pan and Reset in portrait and landscape. Confirm the Link button is absent.
  3. Try Contents, Raw/Preview, Split and multiple tabs. Use Find, dismiss its keyboard and open a diagram fullscreen. Check that focus and the visible document remain correct.
  4. Switch between Light and the other app icons, then return to Original. Check the Home Screen appearance and light/dark themes.
  5. Try an oversized document and an HTTP document URL. Rejection should leave the current document intact.
  6. Quit and reopen the app. On iPad, repeat document, sidebar and diagram checks. Report the device, OS version, build number and steps for any problem.

Mac

  1. Open the bundled Diagram Showcase, then use File > Open to choose your own Markdown through the system picker.
  2. Expand a diagram and check centered zoom, pan and Reset. Confirm PNG/SVG export remains available and the Link button is absent.
  3. Open a folder containing two Markdown files and open both. Choose File > Close Folder: the folder browser should close while both document tabs remain open. Hiding Workspace files alone should leave the folder open.
  4. Edit an open document in your editor and confirm the viewer refreshes, including after Close Folder. Check Raw/Preview, Split, Contents, Find and switching tabs.
  5. Quit and relaunch. Check File > Open Recent and access to a previously selected file. For an unavailable saved startup file, try Locate, cancel, retry and Stop reopening; unrelated tabs and saved entries should remain intact. No QA filename should appear on a clean installation.
  6. Try an oversized file and an HTTP document URL; rejection should preserve the current document. Report the Mac model, macOS version, build number and steps for any problem.

SpecDown Support

Read Markdown specs and plans with interactive Mermaid diagrams.

Get SpecDown

Download free for iPhone, iPad and Mac on the App Store (iOS or iPadOS 16.0 or later; macOS 13.0 or later). You can also choose a direct desktop download for Mac, Windows or Linux.

Getting started

  • Open a file: tap Open on iPhone, use Open Markdown File in the iPad sidebar, or choose File → Open… on Mac. Select a UTF-8 .md or .markdown file, including files in iCloud Drive.
  • From other apps: use Open With… → SpecDown or the share sheet when the app supports it.
  • From the web: paste a public HTTPS link to a Markdown file on the start screen.
  • Try it: open the bundled Diagram Showcase to explore example Mermaid diagrams.
  • Browse a folder: on desktop or in a supported browser, choose Open Folder. Choose Close Folder to close the folder browser while keeping your document tabs open.

Common questions

A diagram shows an error.
SpecDown uses Mermaid syntax. Check that the diagram’s code block starts with ```mermaid.
A document won’t open.
SpecDown supports UTF-8 Markdown files up to 8 MiB. Additional limits apply to long lines, deeply nested content and complex diagrams.
Images don’t appear.
Images linked by a full HTTPS address need an internet connection. On iPhone and iPad, images referenced by a relative path, such as ./diagram.png, aren’t shown yet. Use a full HTTPS image address when sharing a document across platforms.
A link requires sign-in.
SpecDown opens public links without signing in to the host. Some hosts also prevent documents from loading in other apps. Download the Markdown file, then open it in SpecDown.
How do I close a folder?
Choose Close Folder in the folder browser, or File → Close Folder in the desktop app. Your document tabs stay open. Hiding the folder browser only changes its visibility; it does not close the folder.
Can I use the web app offline?
Offline use depends on what your browser has saved. Web links and remote images still need an internet connection.

Privacy Policy

SpecDown for iPhone, iPad, Mac, Windows, Linux and the web.

No accounts, ads or analytics

SpecDown has no account system, advertising or analytics. Documents you open are not uploaded to a SpecDown service.

Documents render on your device

Files you open are read on your device to display them. Recent files, bookmarks and settings are saved in local app or browser storage. Notes in the web and desktop versions are saved there too.

Your file provider or operating system may also store or sync files and backups according to your settings.

When SpecDown uses the network

Opening a web document or an image hosted online sends a request directly to the site hosting that content. That site’s privacy policy applies.

The web app and desktop downloads also check GitHub for releases. App Store versions receive their updates through Apple.
