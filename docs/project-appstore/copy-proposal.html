Description

Read Markdown from your editor or AI assistant in a dedicated reading view.

SpecDown helps developers and people using AI tools review specs, plans, READMEs and technical notes. Open saved Markdown to read formatted tables and highlighted code, then explore Mermaid diagrams with zoom, pan and fullscreen views.

Read your documents
  • Open Markdown from Files or iCloud Drive
  • Send a Markdown document to SpecDown from a compatible app
  • Read headings, lists, tables and highlighted code
  • Jump between sections with the table of contents
  • Find text and move through matching passages
  • Switch between the rendered preview and raw Markdown
  • Compare raw Markdown and the rendered preview in split view
  • Keep several documents open in tabs
Explore Mermaid diagrams
  • View Mermaid flowcharts, sequence diagrams, state diagrams and Gantt charts
  • Expand a diagram to zoom and pan
  • Use Reset to fit the diagram to the current view
Make reading comfortable
  • Choose light, dark or system appearance
  • Use the iPad sidebar to open files and bundled examples
  • Choose from eight app icons, including a separate Light option

The bundled Diagram Showcase works offline. Local documents render on your device. Opening an online document or loading a remote image connects to its host.

No account is required. SpecDown has no ads or analytics.

What’s New

Security and reliability improvements for reading Markdown.

  • Safer handling of document content, large files and complex diagrams.
  • Web documents and remote images now require HTTPS.
  • Rejected documents leave your current document intact.
  • Improved Find behavior for documents with many matches and when the keyboard is open.
  • Diagram zoom controls center the diagram, and Reset fits the current view.
  • Better fullscreen focus and cleanup when switching documents or views.
  • Removed the diagram Link button.
  • A separate Light app icon, plus improved sizing for the existing alternate icons.

SpecDown Support

Read Markdown specs and plans with interactive Mermaid diagrams.

Get SpecDown

Download free for iPhone and iPad on the App Store (iOS or iPadOS 16.0 or later). For Mac, Windows and Linux, get the desktop download.

Getting started

  • Open a file: tap Open on iPhone, use Open Markdown File in the iPad sidebar, or choose File → Open… on Mac. Select a UTF-8 .md or .markdown file, including files in iCloud Drive.
  • From other apps: use Open With… → SpecDown or the share sheet when the app supports it.
  • From the web: paste a public HTTPS link to a Markdown file on the start screen.
  • Try it: open the bundled Diagram Showcase to explore example Mermaid diagrams.
  • Browse a folder: on desktop or in a supported browser, choose Open Folder. Choose Close Folder to close the folder browser while keeping your document tabs open.

Common questions

A diagram shows an error.
SpecDown uses Mermaid syntax. Check that the diagram’s code block starts with ```mermaid.
A document won’t open.
SpecDown supports UTF-8 Markdown files up to 8 MiB. Additional limits apply to long lines, deeply nested content and complex diagrams.
Images don’t appear.
Images linked by a full HTTPS address need an internet connection. On iPhone and iPad, images referenced by a relative path, such as ./diagram.png, aren’t shown yet. Use a full HTTPS image address when sharing a document across platforms.
A link requires sign-in.
SpecDown opens public links without signing in to the host. Some hosts also prevent documents from loading in other apps. Download the Markdown file, then open it in SpecDown.
How do I close a folder?
Choose Close Folder in the folder browser, or File → Close Folder in the desktop app. Your document tabs stay open. Hiding the folder browser only changes its visibility; it does not close the folder.
Can I use the web app offline?
Offline use depends on what your browser has saved. Web links and remote images still need an internet connection.

Privacy Policy

SpecDown for iPhone, iPad, Mac, Windows, Linux and the web.

No accounts, ads or analytics

SpecDown has no account system, advertising or analytics. Documents you open are not uploaded to a SpecDown service.

Documents render on your device

Files you open are read on your device to display them. Recent files, bookmarks and settings are saved in local app or browser storage. Notes in the web and desktop versions are saved there too.

Your file provider or operating system may also store or sync files and backups according to your settings.

When SpecDown uses the network

Opening a web document or an image hosted online sends a request directly to the site hosting that content. That site’s privacy policy applies.

The web app and desktop downloads also check GitHub for releases. App Store versions receive their updates through Apple.

Support email

If you contact support, the message and any attachments you choose to send go to the support mailbox.

Children

SpecDown does not ask children to provide personal information in the app.
