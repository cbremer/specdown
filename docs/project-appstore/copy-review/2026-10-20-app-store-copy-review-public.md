SpecDown App Store Copy Review

English US copy inventory and proposed AI productivity positioning

This is our working document for reviewing the words people see before they try SpecDown. It preserves the saved iPhone, iPad and Mac listing copy, proposes revisions, and collects screenshot captions and related website messaging in one editable place.

Recommended direction: position SpecDown as the Markdown reading companion for AI work. The concrete desktop benefit is a preview that updates when an AI tool or editor saves the file, helping us inspect each revision and guide the next one.

How we will use AI language

The promise is a better way to inspect the documents produced during AI-assisted work. Explain the sequence plainly: the AI tool or editor writes and saves a Markdown file; SpecDown renders it; the person reviews it and asks for the next change.

Keep generation, chat, editing, automatic feedback to an AI agent, and cloud synchronization out of feature claims. None is established by the current app source. Use “live reload” or “automatic refresh when the file is saved” specifically for desktop file-backed documents.

App Review notes

Reviewer-only copy. Saved draft text follows verbatim with paragraph wrapping normalized. No sign-in is required according to the saved notes.

SpecDown is a viewer for Markdown (.md) documents that renders text, tables, code andMermaid diagrams. There is no account, login, purchase or server component.

How to review in under a minute:

1. Launch the app. On iPad, the sidebar shows "Open Sample" and "Open Diagram   Showcase"; on iPhone, the same buttons are on the start screen.2. Tap "Open Diagram Showcase". It renders a bundled document containing every major   Mermaid diagram type (flowchart, sequence, state, Gantt, and more).3. Tap the expand icon on any diagram to open it fullscreen; pinch to zoom and pan.4. Use "Contents" to jump between sections and "Raw" to view the Markdown source.   "Open Sample" includes HTML comments shown as tinted notes; More → "Hide   HTML Comments (2)" hides them and the item then reads "Show HTML Comments (2)".5. To open your own file: tap "Open" and pick any .md file from Files/iCloud Drive,   or use "Open With… SpecDown" / the share sheet from another app.

Network use: the app only goes online when the user opens a web/GitHub link or adocument that references remote images. It contains no analytics, ads or tracking.

App Transport Security: the app's own viewer is bundled and loaded locally.NSAllowsArbitraryLoadsInWebContent is set only so Markdown documents the useropens can display images hosted on plain-HTTP servers. Tapped links open inSafari, not inside the app.

Proposed clarification to add at the beginning

SpecDown supports reviewing Markdown created by external AI tools. It does not generate text, run an AI model, or require an AI account. The automatic refresh of saved local files described in desktop materials is a desktop feature.
