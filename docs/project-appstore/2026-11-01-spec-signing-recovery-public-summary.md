# Public signing recovery boundary

The owner maintains the original signing-backup and recovery runbook privately. Its export destinations, filenames, storage arrangements, temporary keychain checks and recovery procedures are not part of this public repository.

The release process retains reviewed source revisions, artifact hashes, symbol correspondence, channel identities and separate test/signing/upload acceptance records. These public records do not contain private keys or replace the owner's credential backups. No agent may infer permission to create, rotate or use signing credentials from source publication or CI success.

This public summary corresponds to the private November 1 signing-recovery runbook. Its original file hash and exclusion reason are listed in the [publication inventory](2026-11-01-publication-inventory.json); the original remains at its owner-local path, explicitly Git-ignored. Later signing, TestFlight, App Review and public release remain distinct authorized actions.
